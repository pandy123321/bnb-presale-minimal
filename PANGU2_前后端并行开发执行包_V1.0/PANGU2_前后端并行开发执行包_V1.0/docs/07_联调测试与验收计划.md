## 4. 失败恢复

- RPC失败：指数退避、DEGRADED状态；
- Reorg：raw facts标记removed/canonical并重建投影；
- API不可用：前端显示UNAVAILABLE而不是旧数据冒充LIVE；
- Quote过期：强制重新获取；
- Tx dropped/replaced：状态恢复；
- Worker重启：从持久Cursor继续；
- Merkle错误：按批准流程取消或Correction Epoch。
