## 3. 并行冲突规则

以下情况不能并行修改：

- 同一OpenAPI文件；
- 同一状态枚举；
- 同一生成Client输出；
- 同一数据库Migration序列；
- 同一Contract Registry配置；
- 同一CI Workflow。

必须指定唯一Owner，其余任务只消费生成结果。
