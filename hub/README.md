## 约定

1. 新 Web3 项目：在 `hub/<project-name>/` 下独立创建，不要散落在仓库根目录。
2. 仓库根目录只保留：治理规则（`AGENTS.md`、`.cursor/`、`.agent-rules/`）、共享文档（`docs/governance/`）、以及本 hub。
3. 已归档项目以只读基线对待；新功能应开新项目目录，而不是直接在归档目录上扩范围（除非人工负责人明确批准）。
